# Skill Hub 与 Agent 分组切换

本轮将全局页面改为 Skill Hub，只提供发现、搜索、打开来源和收编；删除独立分组页面。各 Agent 维护独立分组，先保存名称和成员，再点击启用。每个 Agent 同时使用一个分组，保存当前分组的修改不会立即操作磁盘，可点击「应用修改」。

分组使用独立副本。切换只撤下由上一分组安装的确切副本，共有成员保留；既有手动安装或注册的 skill 不接管、不移除。若手动 skill 被停用或不可用，会提示先在「管理已安装 skill」处理，不静默修改其状态。副本发生本地修改或替换时阻止切换，保留现场。文件、副本元数据、原生配置与当前分组记录纳入回滚日志；启动恢复未完成的切换。

配置升级为 v2。旧共享分组保留用于既有项目绑定，Agent 页可导入成独立组合。项目引用新的 Agent 专属分组时只应用到对应 Agent。正在使用的分组不能删除；分组使用中的 skill 需先停用后收编，切换 Agent 目录前同样需先停用。
