# Agent 来源统计与设置交互验证

日期：2026-09-24。

## 改动

- Skill Hub 与 MCP Hub 的来源统计项跟随 `disabledAgents`。Claude 的应用 ID `claude-code` 与 MCP ID `claude` 正确对应。当前来源被关闭时清除该筛选，避免留下不可见的筛选条件。
- 关闭 Agent 后同时隐藏其专属未托管 Skill／MCP，列表总数和 token 统计按当前可见内容计算。Hub 托管内容、共享目录，以及其他已开启 Agent 仍在使用的内容继续显示。显示过滤不修改原始资源；重新开启 Agent 后恢复显示。Codex 被关闭时也隐藏其内置 MCP 展示。
- Skill Hub 来源与总量合并到一行：右侧固定总量、备份与 token，左侧空间不足时横向滚动。无可用内容的外部／待确认来源不显示零统计，已选中的筛选保留。
- Agent 开关保存期间局部显示待保存的选中状态，失败后恢复已保存状态。按钮保留 DOM 和焦点，不再通过 disabled 样式让整排按钮闪灰；设置的其他控件也不会因 Agent 开关保存而闪灰。
- 设置写入串行执行。Agent 显示开关不再刷新 CLI 探测；Skill、分组、配置快照标记过期，返回相应页面时刷新，保留退出 Skill 分组管理后的真实状态。目录修改仍会立即刷新 Agent 探测、Skill 扫描和 MCP 状态。
- 设置文案按后端实际行为说明退出 Skill 分组管理，未改变管理开关的后端语义。
