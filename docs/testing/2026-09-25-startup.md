# 启动加载采样与首屏协调

## 范围与方法

- 基线：`c607751`；优化版：本次工作区实现。
- macOS 本机 Tauri Debug App / 真实 WebView 与 IPC，不是 jsdom 模拟耗时。
- 使用 `SKILL_STUDIO_TEST_HOME` 隔离环境：60 个生成的 Hub skill，每个含约 100 行正文；另复制了本机 Codex 的系统 skill 目录。扫描结果为 60 个 skill，Agent 列表为 5 项。
- 未复制真实应用配置、MCP 凭证或项目配置，未改动用户现有 skill。CLI `--version` 使用本机安装的程序。因此这是可控负载对照，不是用户完整工作区或所有平台的性能保证。
- 两版各预热一次 Vite 模块图，然后各执行 3 次完整进程退出／重启。不是操作系统冷缓存测试。
- 临时 Vite 插件记录 IPC 耗时、DOM 出现后的双 `requestAnimationFrame` 时点，以及启动进程的墙钟时间。记录的是首个可绘制时点，不是逐像素绘制完成或动画结束。
- 基线采样使用原前端模块和原后端读锁逻辑；优化版使用本次代码。临时插件与采样入口已从工作区移除，不进入产品。

## 对照结果

单位：毫秒。WebView 时点相对于文档导航起点；进程到首屏为启动墙钟与 WebView 记录换算的近似值。

| 指标 | 基线 1 / 2 / 3 | 优化 1 / 2 / 3 |
| --- | --- | --- |
| 设置 IPC 耗时 | 238 / 240 / 238 | 12 / 11 / 12 |
| Agent 基础列表 IPC 耗时 | 与完整探测共用请求 | 11 / 18 / 11 |
| Agent 完整探测 IPC 耗时 | 733 / 648 / 737 | 554 / 815 / 438，后台执行 |
| Skill 扫描 IPC 耗时 | 247 / 249 / 249 | 234 / 250 / 299 |
| 框架首次可绘制时点 | 322 / 334 / 378 | 619 / 684 / 677 |
| Skill 列表首次可绘制时点 | 588 / 598 / 639 | 619 / 684 / 677 |
| Agent 导航首次可绘制时点 | 1046 / 970 / 1104 | 619 / 684 / 677 |
| 进程启动至上述三部分齐备 | 1675 / 1499 / 1636 | 1190 / 1233 / 1208 |

- WebView 首屏齐备中位数：1046 → 677 ms，约减少 35%。
- 进程启动至首屏齐备中位数：1636 → 1208 ms，约减少 26%。
- 基线框架至 Agent 导航的分批展示间隔：724 / 636 / 726 ms；优化版三部分同一采样帧出现。
- 单看 Skill 列表，它的显示时点不一定提前：统一首屏是以短暂占位换取完整界面，不是让每一个模块都更早出现。
- Skill 扫描本身没有明显加速，本次没有改变全库扫描算法。CLI 探测的耗时仍有波动，但不再影响首屏展示。

## 根因与改动

1. `list_agents` 在执行 CLI 子进程期间持有配置读锁，而 `scan_with_policy` 需要配置写锁。初轮采样曾观察到扫描耗时 1045 ms；根据请求调度顺序，也可能是扫描先占锁，让设置和 Agent 请求等待。改为在读锁内复制配置，释放锁后探测。
2. Agent 基础清单和完整 CLI 探测共用一个查询，导航被版本探测阻塞。拆分基础查询与后台探测，共享 `agents` 查询键前缀，保留统一失效；未确认的 Agent 显示“检测中”，失败显示“检测失败”，不直接误报“未装”。
3. 恢复视图时，设置未加载被当作 MCP 关闭。统一读取初始视图，在设置就绪后决定实际恢复页面，避免临时挂载错误的 Hub。
4. 新增启动边界：只准备设置、Agent 基础清单和恢复页面所需的数据（Skill/备份、分组、项目、配置或 MCP 清单），不加载所有页面、不等待 CLI 探测。首次就绪后不再阻挡刷新或导航。
5. 初始加载失败可重试或继续进入应用处理恢复问题，避免无限占位；后续后台刷新保留已有界面。

## 回归覆盖

`tests/startup.test.tsx` 覆盖：

- 慢设置、慢 Skill 查询和慢 CLI 探测的不同完成顺序；首屏统一展示，CLI 后台补充。
- MCP 视图恢复期间不请求 Skill Hub；禁用 MCP / 隐藏 Agent 的初始视图解析。
- 项目恢复等待必需数据，不先展示空列表。
- 初始化失败后的重试和恢复入口。
- 后台刷新不重新遮挡界面。

原缓存与设置测试更新为分别检查基础清单和 CLI 探测请求，继续验证导航缓存复用、目录修改失效与隐藏 Agent 时不重复探测。

原始采样记录只保留在本机 `/tmp/skill-studio-startup-samples.jsonl` 和 `/tmp/skill-studio-startup-launches.jsonl`，未作为产品文件提交。
