# Hub 托管与还原功能验证（2026-09-16）

## 方法

- Rust 集成测试调用真实 Studio 服务，实际创建文件、符号链接、副本、配置和备份。所有操作位于临时 HOME，由 SKILL_STUDIO_TEST_HOME 隔离，测试结束自动清理。
- React 交互测试通过模拟 IPC 验证按钮、确认弹窗、来源过滤、去重统计和失败反馈；不是原生窗口人工点击测试。
- 未安装、卸载或修改用户的 skill-yuque-cli-guide。

## 验证结果

- 符号链接与复制两种模式：托管、重新加载配置、移出 Hub 还原成功；原始来源不变，Skill Studio 不因托管增加来源计数。
- 同内容多来源合并卡片：托管其中一个来源再还原，总数仍为 1，各来源各计 1。
- 连续三次托管/还原：身份、来源、原生停用状态正确，6 份独立备份保留。
- 备份包含 SKILL.md、资源文件、来源记录和配置快照；还原携带 Hub 最新内容，保留托管前的原始内容备份。
- 原目录被其他内容占用或原位置副本发生修改：拒绝覆盖，Hub 和配置不变；原入口缺失时可还原。
- 活动分组引用中的 skill：禁止直接还原，停用分组后还原并更新引用。
- 项目副本存在本地修改：还原更新来源路径、身份及项目引用，但不覆盖项目修改、不重置副本基线。
- 注入副本元数据写入失败：文件、链接、来源记录和配置一起回滚，失败操作不会遗留成功备份。
- 旧 Hub 条目无来源记录：标记来源待确认，不提供自动还原，不猜测路径。
