# 同仓库 Skill 变体（第一版）

## 行为

- 在线安装只扫描目录白名单：从内置 5 个 Agent 注册表生成仓库根部的标准 Skills 目录，再补充通用入口。不递归搜索整个仓库，不维护不支持 Agent 的黑名单。
- `skills/<name>`、`.agents/skills/<name>` 和仓库根 Skill 作为通用候选；Agent 专用目录来自内置 Agent 注册表的非共享全局路径和项目路径。
- 只检查白名单目录的直接子目录，以及仓库根 `SKILL.md`。插件、hooks、扩展、规则、嵌套 examples 和未知 Agent 目录都不进入候选扫描；即使这些目录里存在同名 `SKILL.md` 也一样。
- 同一适配类别有多个白名单内候选时，按类别显式选择一个。白名单外目录不能通过手工传入候选路径绕过限制。
- Hub 中保留一个逻辑 Skill ID。分组和项目引用该 ID，部署时选“目标 Agent 专用版 → 通用版”，缺少匹配则拒绝，不借用其他 Agent 的专用版。
- 不同仓库同名仍按现有冲突规则拒绝覆盖；本版不引入跨仓库合并或同名覆盖。

## 存储与生命周期

```text
<Hub>/<skill>/
  SKILL.md、scripts/…                  安装时代表版本的预览副本
  .skill-studio-variants/
    generic/                          可选通用内容
    claude-code/                      可选专用内容
    codex/                            可选专用内容
```

预览优先取通用版，否则按稳定顺序取一个专用版。根目录用于保持原有 Hub 身份、预览、整体备份和删除契约，**实际部署与内容编辑使用内部变体目录**。不会将整个聚合目录复制到 Agent；卡片“适配版本”可打开每个实际目录。

`skillInstallations[id].variants` 保存适配 key、仓库相对路径和安装时完整目录 hash。实际部署的复制边车、分组记录和项目记录使用变体真实路径，仍保留逻辑 Skill ID；某个变体修改仅使对应副本过期。软链接到内部变体不会生成额外 Hub 卡片。

组或项目仍引用内部变体、或 Agent 仍有指向变体的软链接时，禁止备份移走整个 Hub 包。解除使用后可整体备份和恢复。多端安装不支持“还原为单个 Agent 来源”。

本版没有自动更新或把已安装单版本静默升级为多变体：已安装内容不覆盖。需要更换安装集合时，先停用相关部署，备份移除原安装，再重新安装。

## 故障隔离与恢复

- Hub 目录仍存在时，安装记录维持 bundle 的逻辑身份；预览 `SKILL.md` 丢失或 YAML 损坏，不影响其他健康变体的发现与部署。单个变体故障显示在对应 Agent 的可用性说明中，不将整张卡片归为失效来源。
- 新部署始终校验实际选中的源，包括普通单版本 Skill；已有专用版损坏时不静默改用通用版。
- 已部署文件的身份识别、原生启停和清理不要求源内容仍健康。清理仍检查副本归属及本地修改；注销和项目移除通过撤销日志同时更新文件和配置，保存失败时回滚。
- 在线候选的 YAML 或哈希错误按目录报告并禁选；存在其他可用候选时，用户确认后可安装健康部分。没有可用候选或显式选择坏候选时拒绝安装。归档路径安全和保留目录检查仍拒绝不安全归档。

## 兼容性

- 配置版本升为 3，版本 2 的单版本记录自动读取，缺少 `variants` 等价于旧单版本行为；不自动移动现有文件或修改分组 ID。
- 旧客户端不理解变体，必须拒绝读取新配置版本，避免把预览或整个聚合目录误部署到 Agent。
- 远程上传携带变体记录，helper 验证 key、来源目录、完整内容 hash 和路径边界。客户端在变体上传前要求 helper 声明 `skillVariants: 1`。
- 通用候选不是“所有 Agent 均已验证兼容”的承诺；扩展 frontmatter 字段使用中性提示，与多端适配信息分开。
- 当前卡片/token 概览来自代表版本；各 Agent 实际使用的版本在适配详情中解释。不安装完整插件、hooks 或扩展。

## 回归入口

- `crates/core/tests/variants.rs`：同一 ID 的差异部署、通用回退、无匹配拒绝、项目事务、分组/项目记录、单变体 drift、软链接去重、删除保护、整体备份恢复、歧义选择和来源校验。
- `crates/remote-helper/tests/protocol.rs`：上传变体记录、实际部署路径和扫描身份。
- `tests/installSkills.test.tsx`、`tests/libraryPage.test.tsx`：分槽选择、卡片说明和扩展字段提示。
